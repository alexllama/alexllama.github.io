As soon as I saw this Info Orbs [kit](https://brett.tech/collections/electronics-projects/products/info-orbs-full-dev-kit) by Brett.tech, I wanted to get it. Not only does it look cool, but you get to put it together. Also, you can code just about anything you want to add to the display. Powered by a ESP32 microcontroller, it displays the weather, stock info, and a clock in a couple of styles. So far I have made a couple of custom clocks, but am looking forward to digging into the code to make other data displays.
